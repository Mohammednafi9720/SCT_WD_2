# Stopwatch Web Application

## Description
An interactive stopwatch web application that allows users to start, pause, and reset time accurately.

## Features
- Start stopwatch
- Pause stopwatch
- Reset stopwatch
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript
